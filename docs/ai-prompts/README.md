# AI 공통 지시문

AI 롤플레이에 쓰는 지시문(프롬프트) 두 개입니다. 상황마다 대본을 쓰지 않고, 이 두 개에
상황 설정(`src/data/situations.ts`의 68개)을 끼워 넣어 모든 상황에 씁니다.

| 파일 | 언제 | 무엇을 돌려주나 |
|---|---|---|
| [`conversation.md`](./conversation.md) | RP-3 대화 중, 학습자가 말할 때마다 | AI의 다음 대사, 영어 뜻, 힌트, 달성한 목표, 대화 종료 여부 |
| [`scoring.md`](./scoring.md) | RP-4, 대화가 끝난 뒤 한 번 | 6개 스킬 점수, 문장 교정, Mistake log에 넣을 오답 |

- 지시문 본문은 영어입니다. 모델이 규칙을 가장 정확히 따르고, 앱 UI 언어(영어)와도 맞습니다.
  학습 내용(한국어 대사)은 한국어로 나옵니다.
- `{{중괄호}}`는 서버가 채워 넣는 값입니다. 각 파일의 "입력" 표에 어디서 가져오는지 적어 두었습니다.
- 출력은 JSON이고, 앱 타입(`src/data/types.ts`)에 그대로 들어가게 맞췄습니다. 그래서 서버가 붙어도
  화면은 고칠 필요가 없습니다.
- 아직 서버가 없어서 실제로 돌려 본 적은 없습니다. 연결할 때 약국·카페 대본
  (`src/data/conversations.ts`)과 비교해 품질을 맞추면 됩니다.

지시문을 고치고 싶으면 이 파일들을 직접 수정하거나, 바꾸고 싶은 점을 말로 요청해 주세요.
