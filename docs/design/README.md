# 디자인

디자인 시안과 디자인 시스템 원본을 올립니다. **여기의 `*.dc.html` 시안이 UI의 유일한 기준입니다.**

핸드오프 문서가 가리키는 파일들 (아직 저장소에 없음):

| 파일 | 화면 |
|---|---|
| `또박이 UI - 전체 화면.dc.html` | 전체 화면 통합 캔버스 |
| `또박이 UI - 00 기능 소개.dc.html` | IN-1 ~ IN-5 (올라옴) |
| `또박이 UI - 01 온보딩.dc.html` | ON-1 ~ ON-4 |
| `또박이 홈.dc.html` | HM-1 |
| `또박이 UI - 02 카테고리 확장.dc.html` | 카테고리 데이터 템플릿 |
| `또박이 UI - 03 롤플레이 v2.dc.html` | RP-1 ~ RP-4 |
| `또박이 UI - 04 복습·미션.dc.html` | RV-1 ~ RV-7 |
| `또박이 UI - 05 마이페이지.dc.html` | MY-1 ~ MY-3 |
| `또박이 UI - 06 정보 노출 원칙.dc.html` | 한/영/로마자 노출 규칙 |
| `support.js` | 시안을 브라우저에서 열 때 필요한 런타임 |
| `design_system_v1.1_foundations.pdf` | 디자인 시스템 파운데이션 |

시안은 서로를 상대 경로(`./파일명.png`, `uploads/파일명.svg`)로 참조하므로
**번들 폴더 구조를 그대로 유지해서** 올려 주세요. 폴더째 끌어다 놓으면 됩니다.

시안에 없는 화면(결제, 동의, 설정 하위 화면 등)은 기존 시안 스타일로 만들어 두었습니다.
해당 화면의 시안이 나오면 여기에 올리고 맞춰 달라고 요청해 주세요.
