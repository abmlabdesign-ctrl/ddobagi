- 날짜: 2026-10-02
- 상태: 적용됨

## 배경

기능 소개(IN)는 `00 기능 소개.dc.html` 기준 5장이었고, 각 장이 색 패널 위 폰 목업에 앱 스크린샷을
넣는 구성이었습니다. 2026-10-02에 최종 디자인(IN-1 · IN-4 화면 시안)과 그래픽 에셋 4개, 확정 문구가 전달됐습니다.

## 결정

- 4장으로 줄이고, 그래픽은 전달받은 PNG를 그대로 씁니다(`assets/intro/intro-1~4.png`). 새로 그리거나 바꾸지 않습니다.
  순서는 에셋 번호대로: 상황 캐릭터 → AI 대화 → 복습 미션 → 리포트.
- 레이아웃은 IN-1 시안(390×844)에서 측정한 값입니다.
  - 상단 `#F7F8FD` 영역에 그래픽을 가운데 두고, 아래 24px에서 흰색으로 페이드
  - `skip`(소문자, 14px, `#585C61`)은 상태바 아래 25px, 오른쪽 24px
  - 제목 18/26 bold 가운데, 9px 아래 본문 14/20 `#6B727A` 두 줄
  - 본문 25px 아래 페이지 점(현재 16×4 주황, 나머지 4×4 `#D1D5D9`, 간격 4)
  - 점 34px 아래 CTA 342×56, 모서리 16, 화면 하단에서 25px(홈 인디케이터가 더 크면 그만큼)
- 그래픽은 원본 크기를 넘지 않고 비율을 유지합니다.
  - IN-1 ~ IN-3: 남는 공간 안에서 통째로 보이게 가운데 정렬(키 작은 기기에서는 그래픽만 작아짐).
  - IN-4: 폰 목업을 `skip` 줄 21px 아래에 원본 크기로 걸고, 상단 영역 끝의 24px 페이드가 덮어 아래가 자연스럽게
    잘려 보이게 합니다. 화면이 짧을수록 덜 보입니다.
- 페이드는 그래픽 위에 겹치는 투명 → 흰색 그라디언트입니다(IN-1 ~ IN-3에서는 이전과 똑같이 보임).
- 동작은 그대로입니다: 스와이프·점 탭으로 이동, `skip`은 About you로, 한 번 본 뒤에는 다시 나오지 않습니다.
  시안에 맞춰 1~3장 하단에 `Next`(다음 장으로)를 두고, 마지막 장 CTA는 `Get started`(About you로)입니다.
  `skip`은 IN-4 시안대로 모든 장에 보입니다.
- 문구는 확정본입니다. 줄바꿈은 IN-1 · IN-4 시안을 따르고, 시안이 없는 IN-2 · IN-3은 자연스러운 곳에서 끊었습니다.
