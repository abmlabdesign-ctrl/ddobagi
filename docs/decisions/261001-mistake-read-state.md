# Mistake log 숫자는 확인하지 않은 오류만 센다

- 날짜: 2026-10-01
- 상태: 적용됨

## 배경

RV-6 대화 화면에서 오류를 열어 봐도 RV-3a Mistake log 숫자가 그대로였습니다. 숫자가
"고치지 않은 오류(`fixed: false`)"를 셌기 때문입니다. `fixed`는 롤플레이를 다시 해서 맞게
말했을 때만 바뀝니다.

## 결정

- `Mistake`에 `read`를 둡니다. RV-6에서 오류 줄을 눌러 Mistake detail을 펼치면 `read: true`가 됩니다.
- 이미 읽은 오류는 다시 열어도 상태가 바뀌지 않아 숫자가 두 번 줄지 않습니다.
- Mistake log의 큰 숫자, `N left across M situations`, 상황별 배지는 **읽지 않은 오류** 수입니다.
  배지가 0이면 숨기고, 상황 줄은 남겨 다시 볼 수 있게 합니다. `Mistakes you fixed`는 그대로 `fixed` 기준입니다.
- 같은 오류를 다음 롤플레이에서 또 틀리면 `read: false`로 다시 셉니다.
- 알림함과 복습 리마인더의 "남은 오류"는 지금처럼 고치지 않은 오류 수를 씁니다.
