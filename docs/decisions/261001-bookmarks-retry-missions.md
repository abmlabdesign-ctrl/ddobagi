# 대화 말풍선 북마크 · 롤플레이 다시 말하기 · 복습 미션 판정

- 날짜: 26-10-01
- 상태: 적용됨
- 정한 사람: 기획 요청, 적용은 Claude (개발 세션)

## 결정

- **말풍선 북마크**: RP-3b(Script)와 RV-6(대화 스크립트)의 모든 말풍선에 북마크. 상대 말풍선은 오른쪽 바깥,
  내 말풍선은 왼쪽 바깥, 세로 가운데, 간격 8. outline ↔ filled 토글이고 Scrapbook에 저장/해제됩니다.
  같은 한국어 문장이 이미 Scrapbook에 있으면 저장된 상태로 보입니다.
- **롤플레이 다시 말하기**: Level check와 같은 방식. 녹음을 멈추면 바로 넘어가지 않고 양옆 버튼이
  `Try again` / `Submit`으로 바뀝니다. Try again은 들린 말을 지우고, Submit이 다음 턴으로 넘깁니다.
- **로마자 툴팁**: 모든 한국어 낱말에 툴팁. 데이터에 없는 낱말은 기기 안 규칙 변환(`services/romanize.ts`).
- **Speak without pausing**: 문장 끝 낱말까지 주황색이 채워지면 정답(인식 문장이 완전히 같지 않아도).
- **Write it from the meaning / Fill in the particles / Rewrite it politely**: 소리 버튼은 채점 전에도 정답이 채워진 완성 문장을 읽습니다.
- **Repeat final consonant sounds**: 인식된 말에 순서대로 들어 있는 음절까지 주황색으로 칠합니다.

## 한계 (서버/API 없이는 불가)

- 받침을 정확히 발음했는지는 판정하지 못합니다. 브라우저 음성 인식은 글자만 돌려주므로,
  주황색은 "그 음절로 알아들었다"는 뜻입니다. 발음 평가 API가 필요합니다.
- 실제로 멈칫했는지(쉼)를 재지 못합니다. 같은 이유로, 끝까지 읽혔는지만 봅니다.
- 음성 인식은 웹(Chrome·Edge·Safari)에서만 동작합니다. 그 밖에서는 시간에 맞춰 칠해지는 목 동작입니다.
- 로마자 규칙 변환은 구개음화(같이 → gachi) 같은 낱말별 예외를 다루지 않습니다.
