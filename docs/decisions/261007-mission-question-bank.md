# 미션 문제 은행 확장과 최근 문제 회피 출제

- 날짜: 26-10-07
- 상태: 적용됨 (문항은 한국어 교육 담당 검수 필요)
- 정한 사람: 기획 요청 — Review / Micro mission 6축 문제 추가

## 배경

축마다 문제가 1~2개뿐이라, 미션을 열 때마다 같은 문제가 같은 순서로 반복됐습니다
(`questionCount`만큼 같은 문제를 돌려 씀).

## 결정

- 축마다 문제 은행을 8문제로 맞췄습니다(총 38문제 추가, 전체 48문제, `src/data/missions.ts`). 유형과 데이터 구조는 그대로입니다.

  | 축 | 유형 | 문제 수 (기존+추가 = 8) | 새 문제가 다루는 것 |
  |---|---|---|---|
  | Pronunciation | speak | 2+6 | 겹받침(ㄺ·ㄵ), 연음, 된소리화(맛있게·밖에) |
  | Fluency | speak | 1+7 | 연결어미(-고·-아서·-면·-으면), 긴 명사구, 의문문, 정중한 부탁 |
  | Particles | write | 2+6 | 은/이, (으)로·을, 랑/와/하고, 한테서/에게서, 부터·까지, 도 |
  | Endings | write | 2+6 | -(으)ㄹ게요, -(으)ㄹ까요, -고 싶어요, -네요, -아/어 주세요, -고 있어요 |
  | Politeness | write | 2+6 | 이야→예요, 식사하셨어요, 감사합니다, 주세요, 죄송합니다, 사세요(ㄹ 탈락) |
  | Context | choice | 1+7 | 약국·계산대·친구·길 묻기·직장·호텔·식당 — 보기 2~3개, 정답 위치 섞음 |

- 출제는 `src/services/questionPicker.ts`가 합니다(LLM·API 없음).
  - 한 번도 안 나온 문제 → 오래전에 나온 문제 순으로 `questionCount`만큼 뽑고, 같은 순위 안에서는 섞습니다.
  - 바로 전 실행에서 나온 문제(최근 기록의 앞쪽 절반)는 이번 실행의 뒤쪽으로 보내, 같은 문제로 시작하지 않습니다.
  - Today's focus(혼합 10문제)도 같은 기준으로 축마다 고릅니다.
  - `Retry`도 새로 뽑습니다(이전에는 단일 축 미션은 같은 순서 그대로).
- 최근 나온 문제는 `recentQuestions`(최대 60개)로 기기에 저장되어 앱을 다시 열어도 이어집니다.

## 이유

문제 은행이 실행 길이(4~8문제)보다 조금 커서, 완전 랜덤이면 같은 문제가 연달아 나오기 쉽습니다.
"오래 안 본 것부터"가 적은 문제로도 가장 고르게 돌아갑니다.

## 남은 것

- 새 문항은 원어민·한국어 교육 담당 검수 전입니다. 특히 쓰기 문제의 허용 답안(`blanks`)이 충분한지 확인이 필요합니다.
- 한 번에 푸는 문제 수(`questionCount`)는 축마다 그대로입니다: Pronunciation 6 · Fluency 4 · Particles 7 ·
  Endings 6 · Politeness 8 · Context 5. Politeness는 은행과 실행 길이가 같아 매번 8문제가 다 나오고 순서만 바뀝니다.
  더 다양하게 하려면 문제를 더 추가하면 됩니다. 출제 코드는 고칠 필요 없습니다.
